# 故障排查

## 健康检查显示未就绪

- `SAM3 · WaveSpeed`：检查 `WAVESPEED_API_KEY`。
- 图像模型：检查 `IMAGE_API_KEY`、`IMAGE_API_BASE_URL` 和 `IMAGE_MODEL`。
- 修改 `.env` 后重启进程。

## SAM3 没选完整

优先把“书”改成“右侧人物手中的书”这类位置明确的短语。不要用一大段生成要求做分割词。若服务能识别多个同类对象，增加方位或所属关系。

## 旧对象边缘仍可见

把“清除旧边缘”从 6 px 提高到 8–12 px。若是大对象，应先确认 SAM3 蒙版本身没有漏掉主体；dilation 只能清理轮廓，无法修复大面积漏选。

## 新对象被截断

提高“新对象可用空间”。新对象尺寸明显大于旧对象时，默认 0.35 可能不够；选择更大范围会增加模型自由度，也更可能影响邻近内容。

## 接缝明显

先检查供应商原图是否已经在边界处产生色差。可把羽化从 3 px 调到 4–6 px；过大的羽化会让轮廓发虚。代码的羽化只向编辑蒙版内部发生，外部像素仍保持原样。

## 中文文字不准确

这是生成模型能力边界，不是把 dilation 调大就能解决。缩短文本、把准确字符放在引号内、明确“不得增减字符”会有所帮助；商业交付应使用排版工具重建文字。

## 请求超时

失败任务与中间文件仍会保留。点击“重新执行”会创建新的付费请求。由于通用 API 没有统一异步 job id，本项目不自动假设旧请求未执行；生产集成应在 provider adapter 内保存供应商任务 ID 并实现查询。

## 结果尺寸不一致

检查兼容服务是否接受请求中的 `size=宽x高`，以及它是否返回了其他比例。Simple Fill 会把供应商输出归一化回裁剪画布再回填，但严重的比例变形说明供应商协议不兼容，应修改 `app/image_provider.py`。
