# 示例任务手册

以下示例都是“用户确认一次蒙版后，固定输入直达函数链路”的写法。不要把多个无关修改塞进一个任务；一次只选一个语义对象，结果通常更稳定。

## 1. 书替换成白猫

选择对象：

```text
右侧人物手中的书
```

生成要求：

```text
把书完整替换成一只被人物双手自然抱住的白色长毛猫。猫的体积与原书所在区域协调，完整显示双耳和前爪；保持人物身份、脸、手臂、袖口、背景、插画线条、配色和构图不变。
```

建议：默认参数；若猫耳被裁断，把“新对象可用空间”改为“更大范围”。

## 2. 普通眼镜替换成星形眼镜

选择对象：

```text
人物脸上的眼镜
```

生成要求：

```text
把现有眼镜替换成与插画风格一致的星形镜框眼镜，镜腿与脸部透视自然，眼镜尺寸合理；保持人物脸型、五官、头发、表情和其余画面不变。
```

建议：对象很小时用“接近原对象大小”，羽化 1–3 px。

## 3. 花瓶改成红色

选择对象：

```text
右侧桌面上的花瓶
```

生成要求：

```text
保持花瓶的造型、尺寸、位置、材质、高光和阴影不变，只把花瓶主体改成与旁边桌面一致的红色；保持花枝、桌面和背景不变。
```

建议：这种“只改属性”的任务应明确写“造型、位置不变”。

## 4. 机器人替换成猫形机器人

选择对象：

```text
画面中央的机器人
```

生成要求：

```text
把中央机器人替换成猫形态的友好 AI 机器人，保留同样的蓝白半透明科技材质、正面姿态、发光效果、大小和中心位置；外轮廓具有猫耳与柔和猫脸特征，保持周围屏幕、光环、文字和背景不变。
```

建议：新轮廓比旧对象更宽时用“更大范围”。

## 5. 海报短标题替换

选择对象：

```text
海报中部的白色大标题
```

生成要求：

```text
把选中标题替换成“葡萄美酒夜光杯”，保持原标题的倾斜方向、字重、白色主体、蓝色投影、行距和视觉占位，其他内容不变。文字必须准确可读，不增减字符。
```

注意：图像模型对精确中文、字体复刻和品牌字标仍可能失败。对文字准确性要求高时，应将生成结果作为视觉草稿，最后用排版工具落字。

## 6. Prompt 编写公式

```text
把【旧对象】替换/修改为【新对象或属性】；
新对象需要满足【尺寸、位置、视角、关系】；
保持【关键人物/前景/背景/画风/光照】不变。
```

好提示词应描述约束，但不要虚构坐标或重复十几遍“绝对不变”。真正的硬边界由蒙版和最终合成保证，不靠语言保证。

机器可读版本见 [`examples/prompts.json`](../examples/prompts.json)。
